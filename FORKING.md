# Forking Guide
Fork 指南

This course is MIT licensed. You're free to fork it and adapt it for your needs. Here's how to do it well.
本课程采用 MIT 许可证。你可以自由 fork 并按你的需求进行改编。以下是做好这件事的方法。

## For Teams
适用于团队

Want to use this as internal training? Fork and customize:
想把它用作内部培训？请 fork 并自定义：

1. Fork the repository --- Fork 该仓库
2. Remove phases your team doesn't need --- 移除你的团队不需要的阶段
3. Add company-specific examples and data --- 添加公司特定的示例和数据
4. Add internal tool integrations to the outputs --- 在 outputs 中添加内部工具集成
5. Keep the attribution — it helps the community grow --- 保留署名——这有助于社区发展

## For Schools & Universities
适用于学校和大学

Want to use this as course material?
想把它用作课程材料吗？

1. Fork the repository --- Fork 该仓库
2. Map phases to your semester schedule --- 将各阶段对应到你的学期安排
3. Add grading rubrics to exercises --- 为练习添加评分标准
4. Add your own assignments and exams --- 添加你自己的作业和考试
5. Consider contributing improvements back upstream --- 考虑将改进贡献回上游

## For Bootcamps
适用于 Bootcamp

Running a paid bootcamp? That's fine under MIT.
在收费 Bootcamp 中运行这个项目？这在 MIT 下是允许的。

1. Fork and structure for your cohort timeline --- fork 并按你的学员时间线进行组织
2. Add video content, live sessions, mentorship --- 添加视频内容、直播课程和导师指导
3. The code and docs are yours to build on --- 代码和文档都可以由你在此基础上继续构建
4. Consider sponsoring the project or contributing back --- 考虑赞助该项目或回馈贡献

## For Other Languages
适用于其他语言

Want to teach this curriculum in a different programming language?
想用不同的编程语言来教授这套课程吗？

1. Fork the repository --- Fork 该仓库
2. Re-implement code examples in your language --- 用你的语言重新实现代码示例
3. Keep the lesson structure and documentation --- 保留课程结构和文档
4. Submit a PR to link your fork from the main README --- 提交一个 PR，在主 README 中链接到你的 fork

## Keeping Your Fork Updated
保持你的 fork 为最新状态

```bash
git remote add upstream https://github.com/rohitg00/ai-engineering-from-scratch.git

git fetch upstream
git merge upstream/main
```
